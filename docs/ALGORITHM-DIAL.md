# Algorithm dial shortcut

In v1.0.0-beta, turning ALGORITHM from Home or another editor selects the algorithm screen and applies the existing routing adjustment, including at a clamped endpoint. Existing page-change handling resets acceleration and redraws. Diagnostic pages retain their dial behavior.

Native shortcut/editor tests check Home and ENV entry, algorithm adjustment, diagnostic navigation and return Home. DSP, queues and parameter staging are unchanged. See [release validation](RELEASE-1.0.0-beta.md) for the final seven-voice policy and build.
