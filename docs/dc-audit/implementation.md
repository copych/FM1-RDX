# DC removal implementation

Baseline acfc910; 1.0.2-dev local firmware SHA256 5a0deffd35cad7a0f6a0b25ec3ff9305d51b76a63c0f093646e2effccfc2bae9. Built-in build ID remains 79B2B265 because the identifier does not cover all included DSP sources; use the pinned package SHA, not that identifier, to distinguish this preview. Exact firmware/WASM identities and AC sweep summary: implementation-artifacts.json.

A normalized first-order 2 Hz high-pass at 44100 Hz now runs on the CPU0 completed dry mix, including when FX are bypassed. Each active effect slot is DC-filtered before post-slot gain matching, preventing one effect's bias from entering the next. A final filter after the metronome and before lookahead peak protection catches remaining bias. Operator waves, feedback, envelopes, CPU1 generation, buffer sizes and output lookahead are unchanged. The maximum four new stages together attenuate 27.5 Hz by approximately 0.09 dB; each is sample-continuous with no additional buffering delay.

The implementation uses a leaky mean estimate: d=x-mean; mean+=(1-exp(-2*pi*2/44100))*d; y=d*(1+exp(-2*pi*2/44100))/2. Coefficients are baked float literals; no runtime transcendental/division/double operations. Inputs are finite-checked and tiny estimates zeroed. Input and slot state reset on effect prepare/panic; final state resets on application init/phrase panic. Raw source-fidelity effect comparisons using matchLevels=false intentionally bypass the new post-slot filter as well as makeup. Production always uses the normal path. No original effect-local blockers were removed.

The earlier RMS sweep is now AC-based: each channel's mean-square component is excluded before computing calibration-validation RMS. Existing gain tables were retained after the independent sweep passed; they were not regenerated or replaced by another limiter. Current measurements cover 24 maximum feedback/type/note/polyphony cases, 156 independent input/parameter settings and 64 effect chains. Independent AC RMS deltas remain -1.36..+1.88 dB. Peak protection remains -1 dBFS. These are signal RMS comparisons, not perceptual loudness normalization.

132 dry/wet factory/Init cases were repeated, retaining both means, total RMS and AC RMS in after.json. SolPhase note69 dry mean fell from -0.06429 to 0.00000085 FS; factory-FX left mean from -0.08003 to 0.00001127 FS. Worst measured RMS inflation from finite-window mean across all cases is now 0.0202 dB (previously up to 9.90 dB). Slow musical modulation and finite windows can leave nonzero means; the tool guards SolPhase mean below 0.0001 FS and all cases below 0.05 dB inflation. This does not make all presets equally loud.
