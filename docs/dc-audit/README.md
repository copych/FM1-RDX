# DC offset audit

Measured locally with the current WebAssembly emulator, baseline 4273795 / build 79B2B265. Run `node tools/audit-dc-emu.mjs`. No firmware or sound processing was changed. Results are in results.json.

132 cases: all 33 factory/Init programs, MIDI notes 48 and 69, velocity 127, factory FX or both slots THRU. Body measured for two seconds after one second of settling; released-note tail measured for one second after three seconds settling. Both channel means, total RMS, mean-removed AC RMS and peak measured. Finite-window mean can include slow musical modulation; this is not by itself proof that every measured mean is stationary DC.

SolPhase (MIDI program 24, displayed bank 4 slot 1) shows a substantial offset even dry: note69 mean -0.06429 full scale, total RMS 0.07694; DC inflates total RMS by 5.20 dB. With factory effects mean is about -0.0800 per channel; total RMS 0.08466 versus AC RMS 0.02764 left (9.72 dB inflation), right inflation 9.90 dB. Note48 dry inflation is 5.89 dB. Chopper dry also shows about -0.0136 at note69, inflating RMS by 4.16 dB. These are output measurements, not internal stage taps.

Source inspection: no general blocker in RdxOutput or dry engine output. Operator phase modulation/feedback can yield asymmetric waveforms; adding filtering inside the operator feedback path would change synthesis, so it is not a justified fix from output evidence alone. TouchWah and Phaser have blockers in their wet paths. Reverb filters its wet input but mixes the unfiltered dry signal back. Distortion has no blocker. Therefore existing effect-local filters do not ensure a centered final output, and dry signal can carry bias through effect mixtures.

The calibration's squared-sample power measurements include DC; this can distort loudness estimates and spend limiter headroom. Removing DC will not normalize the musical loudness differences of all presets. Recommended correction boundary: dry mix before effects (so distortion/envelope followers do not react to bias), and output after effects before peak protection to catch newly generated bias. Preserve operator/feedback math. Select a low cutoff and verify bass response/transients, reset behavior and zero-input decay before implementation; remeasure/rederive FX calibration using AC signal power rather than accepting current tables unchanged.

This is a read-only DSP investigation plus a host measurement tool: target/ABI, audio hot-path numerics, execution ownership, memory/storage/I/O, dependencies/licenses and package/recovery are unchanged (N/A to firmware modification). Host measurement PASS: 132 emulator cases completed, raw results retained. Hardware validation UNVERIFIED: no direct USB PCM/analog measurement or device timing was performed. No new firmware package was produced. Finite-window musical drift, onset behavior, all FX parameter combinations and true perceived loudness were not exhaustively tested.
