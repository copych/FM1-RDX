# Preset selection returns Home — Preview 2026.11.21-9

PRESET movement returns the editor to Home, closes Audio Timing and resets knob acceleration. Valid received MIDI program changes do the same, including selecting the current preset again. Unsupported programs and messages filtered by MIDI receive channel do not change navigation. Source DSP, USB audio, LFO fix and patch parameters are unchanged.

Panel navigation runs on the main loop. MIDI runs in app_render and publishes a one-byte Home request; the main loop takes/clears it under existing interrupt exclusion and performs the UI changes. The audio callback does no drawing or extra I/O. Existing editor/event ownership is retained. PRESET movement at a bank boundary still returns Home.
